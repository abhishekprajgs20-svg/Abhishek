ABHISHEK APP - KAISE CHALAYEIN  (v2)
====================================
PEHLI BAAR:
1. ZIP ko EXTRACT karo (right-click -> Extract All). ZIP ke andar se mat chalana.
2. GitHub par PAT banao: Settings > Developer settings > Personal access tokens > Tokens (classic)
   'repo' aur 'workflow' DONO tick karo. Token copy kar lo.
3. UPLOAD_KARO.bat par double-click karo.
4. Poochhe jaane par daalo: repo ka naam, GitHub username, PAT.
   (Purana repo update karna ho to wahi naam likho aur 'y' dabao.)
5. Script upload karegi, APK build karwayegi (8-12 min) aur is folder me ABHISHEK.apk save kar degi.
6. ABHISHEK.apk phone me bhejo aur install karo.
   (Purani ABHISHEK app hai to bas upar se install kar do, update ho jayegi.)

FILES KAHAN SAVE HOTI HAIN (v2):
 Tool se jo bhi file download karo (PDF, ZIP, TXT...) wo seedha phone ke
 Files app -> Downloads -> ABHISHEK folder me save hoti hai. Share menu nahi aata,
 ek saath kitni bhi files save ho jati hain. Screen par "Save ho gayi" likha aata hai.
 Android 9 ya purane phone par pehli baar storage permission puchhega - Allow karo.

NAYI HTML JODNI HO:
 A) Bina dobara build kiye: app kholo -> neeche "HTML jodo" -> phone se HTML file chuno.
 B) Hamesha ke liye (APK ke andar): HTML ko "tools" folder me daalo -> UPLOAD_KARO.bat chalao.
    Dhyan: "tools" folder me jo HTML nahi hogi wo app se hat jayegi.

HTML HATANI HO:
 - "HTML jodo" se jodi hui: card ke kone me X dabao.
 - tools folder wali: file folder se delete karo aur UPLOAD_KARO.bat dobara chalao.
