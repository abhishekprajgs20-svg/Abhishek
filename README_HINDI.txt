ABHISHEK APP - KAISE CHALAYEIN
==============================
PEHLI BAAR:
1. ZIP ko EXTRACT karo (right-click -> Extract All). ZIP ke andar se mat chalana.
2. GitHub par PAT banao: Settings > Developer settings > Personal access tokens > Tokens (classic)
   'repo' aur 'workflow' DONO tick karo. Token copy kar lo.
3. UPLOAD_KARO.bat par double-click karo.
4. Poochhe jaane par daalo: repo ka naam (jo chaho), GitHub username, PAT.
5. Script upload karegi, APK build karwayegi (8-12 min) aur is folder me ABHISHEK.apk save kar degi.
6. ABHISHEK.apk phone me bhejo aur install karo.

NAYI HTML JODNI HO:
 A) Bina dobara build kiye: app kholo -> neeche "HTML jodo" -> phone se HTML file chuno. (turant jud jati hai)
 B) Hamesha ke liye (APK ke andar): HTML ko "tools" folder me daalo -> UPLOAD_KARO.bat chalao
    (wahi repo ka naam dena, "y" dabana). Nayi APK ban jayegi.

HTML HATANI HO:
 - "HTML jodo" se jodi hui: card ke kone me X dabao.
 - tools folder wali: file folder se delete karo aur UPLOAD_KARO.bat dobara chalao.
