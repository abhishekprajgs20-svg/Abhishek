YAHAN APNI HTML FILES DAALO
===========================
Is "tools" folder me jo bhi .html file rakhoge, wo ABHISHEK app me apne aap load ho jayegi.
Phir UPLOAD_KARO.bat chalao - nayi APK ban jayegi.
Kisi tool ko hatana ho to uski HTML yahan se delete kar do aur dobara UPLOAD_KARO.bat chalao.
(Bina APK dobara banaye HTML jodni ho to app ke andar "HTML jodo" button use karo.)
